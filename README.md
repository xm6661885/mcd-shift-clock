# 倒班生物钟点餐 · mcd-shift-clock

> 你的早上，可能是下午四点。

夜班护士、工厂倒班、值班保安、刚落地倒时差的人，作息和钟表时间对不上。普通点餐助手按"现在几点"推荐，凌晨 1 点推荐的永远是宵夜。这个 Skill 按**你的作息**来排：

- 起床餐、班中餐、下班餐，各自有热量区间和咖啡因规则（下班睡前那餐不给咖啡）；
- 每个时间点对上门店**真实的供餐时段**：同样是早上 7:20，对夜班的人来说是睡前那餐，给的是早餐菜单里的轻量选择；
- 深夜自动筛出 **24 小时门店**；
- 价格用官方接口算出，营养用官方营养数据。

## 真实运行示例

在中山一院附近上夜班，16:00 起床，19:00 上班，次日 07:00 下班：

```
作息：16:00 起床，19:00-07:00 上班

· 2026-10-11 16:30 起床餐（你的早餐）
  麦当劳广州龟岗大马路餐厅（00:00-23:59，下午茶）：麦香鸡 + 纯牛奶(盒装)，¥27.50
  约 498 kcal，蛋白质 22g
· 2026-10-12 01:00 班中餐
  麦当劳广州龟岗大马路餐厅（00:00-23:59，宵夜）：双层吉士汉堡 + 纯牛奶(盒装)，¥33.50
  约 558 kcal，蛋白质 34g（该时间预约尚未开放，按同时段菜单预估）
· 2026-10-12 07:20 下班餐（睡前别太撑，不要咖啡因）
  麦当劳广州龟岗大马路餐厅（00:00-23:59，早餐）：火腿扒麦满分 + 纯悦，¥17.50
  约 261 kcal，蛋白质 14g（该时间预约尚未开放，按同时段菜单预估）

营养来自 list-nutrition-foods，价格来自 calculate-price；仅供参考，不构成医疗或营养建议。
```

## 目标用户

- 医护、安保、工厂、物流等倒班人群
- 程序员值班、运维 oncall
- 跨时区出差刚落地、生物钟还没调过来的人

## 安装

1. 在 [麦当劳 MCP 开放平台](https://open.mcd.cn/mcp) 申请 Token。
2. 参考 `mcp-config.example.json` 在 Agent 里配置 `mcd-mcp`。
3. 导入本仓库作为 Skill（`SKILL.md`）。
4. 如需直接运行脚本：`export MCD_MCP_TOKEN=你的Token`（Python 3.9+）。

## 使用示例

- "我这周上大夜，晚上 7 点到早上 7 点，下午 4 点起床，帮我排一下三顿"
- "凌晨 2 点医院附近有哪家麦当劳开着？"

```bash
python3 scripts/shift_clock.py plan --city 广州市 --keyword 中山大学附属第一医院 \
  --date 2026-10-11 --wake 16:00 --shift-start 19:00 --shift-end 07:00
```
